# Conceitos aprendidos

Índice dos conceitos registrados a partir das conversas sobre o projeto.
Cada conceito terá uma nota Markdown com explicação, exemplo e aplicação no TCC.

Use a skill `$registrar-conceito` para escolher o próximo aprendizado a documentar.

## Índice

- [Chunking e sobreposição](chunking.md) — Divisão das notas em trechos de até 500 caracteres, ajustes das bordas e impacto da sobreposição na recuperação.
- [Embeddings](embeddings.md) — Representações vetoriais de textos, aplicação na busca RAG e aprendizados da migração para a API do Google.
- [RAG](rag.md) — Recuperação de trechos da base médica e geração de respostas com Gemini, incluindo o fluxo e os limites da implementação no projeto.
